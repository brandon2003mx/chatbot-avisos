# Base de datos

## Colección: estudiantes

Contiene los datos de los estudiantes que recibirán avisos.

Campos:

- nombre
- matricula
- carrera
- semestre
- grupo
- telegramId
- fcmToken
- activo

## Colección: usuarios

Contiene coordinadores y administradores.

Campos:

- nombre
- correo
- rol
- activo

## Colección: avisos

Contiene los avisos creados por los coordinadores.

Campos:

- titulo
- contenido
- tipoSegmentacion
- carrera
- semestre
- grupo
- autorId
- activo
- fechaCreacion
